# 오늘의 할 일

HTML, CSS, JavaScript만으로 만든 모바일 친화적인 할 일 관리 웹앱입니다. 프레임워크, 패키지 설치, 외부 API 또는 백엔드 서버가 필요하지 않습니다.

## 실행 방법

1. 저장소를 내려받거나 복제합니다.
2. `index.html`, `style.css`, `script.js`가 같은 폴더에 있는지 확인합니다.
3. `index.html`을 브라우저에서 엽니다.

브라우저의 `localStorage`는 `file://` 환경에서 브라우저별 차이가 있을 수 있으므로 저장 기능 테스트에는 아래의 선택적 로컬 서버 실행을 권장합니다.

```bash
python -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`에 접속합니다. 이 서버는 정적 파일을 제공하기 위한 개발용 선택 사항이며, 앱에는 백엔드가 없습니다.

## 기능

- 할 일 추가 (빈 입력 방지)
- 완료 표시 및 완료 취소
- 할 일 개별 삭제
- 전체 / 진행 중 / 완료 필터
- 완료 항목 한 번에 지우기
- 완료 개수와 진행률 표시
- `localStorage`를 이용한 브라우저 내 저장
- 모바일 반응형 레이아웃 및 키보드 접근성 지원

## 테스트 체크리스트

- [ ] 할 일을 입력하고 추가하면 목록에 나타납니다.
- [ ] 새로고침 후에도 목록이 유지됩니다.
- [ ] 완료 버튼을 누르면 완료 상태와 진행률이 바뀝니다.
- [ ] 완료한 항목을 다시 누르면 미완료로 돌아옵니다.
- [ ] 개별 삭제와 완료 항목 일괄 삭제가 동작합니다.
- [ ] 전체 / 진행 중 / 완료 필터가 올바르게 동작합니다.
- [ ] 모바일 화면에서 입력창과 버튼이 가로로 넘치지 않습니다.

## 데이터 및 개인정보

할 일은 현재 브라우저의 `localStorage`에만 저장되며 서버로 전송되지 않습니다. 같은 브라우저와 저장소에서 유지됩니다. 브라우저 데이터를 지우거나 시크릿 창을 닫으면 저장한 데이터가 사라질 수 있습니다.

## 파일 구성

- `index.html` — 페이지 구조
- `style.css` — 반응형 스타일
- `script.js` — 할 일 관리 및 로컬 저장
